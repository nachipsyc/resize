# resize

ディレクトリ内の JPEG を、**目標ファイルサイズ以下に収まるよう自動圧縮**する CLI ツールです。

幅の縮小率(scale)と JPEG 品質(quality)を試行しながら少しずつ調整し、指定した下限サイズを下回るまで圧縮します。Exif / IPTC / ICC などのメタデータ(APP セグメント)は元ファイルから抜き出して保持します。

## 仕組み

1. ソース(`-source`)ディレクトリの JPEG を最大 4 並列で処理する
2. ファイルサイズが `-lower` 未満のものはそのままコピーする
3. `-lower` 以上のものは、scale と quality を段階的に下げながらエンコードを繰り返し、`-lower` 以下になった時点で確定する
4. エンコード後の JPEG に元画像のメタデータ(APP0〜APP15)を差し込み、ターゲット(`-target`)へ同名で保存する

> 注意: 圧縮の限界(scale < 0.05 または quality < 15)に達した場合は、それ以上縮められず元画像に近いものが出力されることがあります。`-target` ディレクトリは事前に作成しておいてください。

## 使い方

```bash
# 10MB(デフォルト)を超える JPEG を 10MB 以下に圧縮して target へ書き出す
go run resize.go -source=<ソースディレクトリ> -target=<ターゲットディレクトリ>

# 下限サイズを 5MB(5000000 byte)に指定
go run resize.go -source=<ソース> -target=<ターゲット> -lower=5000000
```

### オプション

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `-source` | （必須） | ソース画像ディレクトリのパス |
| `-target` | （必須） | ターゲット画像ディレクトリのパス |
| `-lower` | `10000000` | この byte 数以下を目標に圧縮する。これ未満のファイルは無加工でコピー |

```

...

```
